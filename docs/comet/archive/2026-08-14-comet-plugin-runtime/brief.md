# Outcome

为 Comet 提供公开、稳定、可插拔的插件运行时，让第一方和第三方插件通过同一套接口接入。个人记忆、项目规则和 Dashboard 宿主会在依赖 child 中消费这套运行时。

# Scope

- 管理插件发现结果、安装、启用、停用、更新、卸载、兼容性检查和生命周期状态。
- 为插件提供来源事件、受控上下文请求、用户/项目作用域、只读配置、插件级隔离存储和统一诊断。
- 为插件提供公开的能力调用和 Dashboard 页面贡献接口；运行时只负责贡献数据，不实现 Dashboard 主机页面。
- 第一方插件默认协调安装，保留用户主动停用或卸载的状态；第三方安装和更新必须来自明确的用户动作。
- 插件失败、缺失或不兼容时隔离该插件，其他插件和宿主 workflow 继续运行。

# Non-goals

- 不在本 child 实现个人记忆、项目规则、Skill/CLI 交互或 Dashboard 主机页面。
- 不根据项目内容静默下载、安装或执行第三方插件。
- 不允许插件直接改写 Comet workflow 状态机、Guard 或其他插件私有存储。
- 不在本 child 固定插件包格式、进程模型、线协议或宿主接线方式。

# Acceptance examples

- 第一方和第三方插件共享安装、启用、停用、更新、卸载、兼容性和诊断接口；第三方安装/更新拒绝非用户动作来源。
- 第一方插件首次协调时自动启用；用户显式停用或卸载后，后续协调和版本更新保留该选择。
- 停用立即停止事件、上下文、能力调用和页面加载，但不删除插件状态或插件数据；更新会销毁旧活动实例。
- 事件带有来源和作用域；上下文、能力调用和 Dashboard 贡献按用户或项目作用域路由，项目暂停只影响指定项目。
- 每个插件只能获得自己的配置、存储和诊断通道；插件不能通过运行时 API 访问其他插件私有数据。
- 不兼容、启动、事件、上下文、能力或页面贡献失败都会产生带插件标识的诊断，不阻断健康插件。
- 一个最小第三方插件可以安装、启用、接收事件、调用能力、停用和卸载；JSON 状态适配器可以恢复生命周期状态。

# Constraints and invariants

- 本 child 只覆盖插件运行时边界；Supervisor Change 的完整产品验收由个人记忆、项目规则和 Dashboard child 继续完成。
- 插件生命周期状态只有一份领域来源；未来 Skill、CLI 和 Dashboard 必须复用本运行时，不能维护副本。
- 第一方与第三方插件遵循相同的公开接口和兼容性规则。

# Decisions

- 父级 Shape 已确认本 child 为第一波唯一可执行 child；个人记忆和项目规则依赖本 child 完成，Dashboard 依赖两个领域 child 完成。
- 该 child 使用独立 worktree，在 `comet/comet-plugin-runtime` 分支实现，目标分支为 `beta20`。

# Open questions

无。新增用户可见决定必须返回 Supervisor Change Shape。

# Verification expectations

- 验证第一方与第三方生命周期、显式用户动作、版本升级状态保留、作用域和项目暂停。
- 验证来源事件、配置、隔离存储、能力调用、Dashboard 贡献和失败诊断。
- 验证 JSON 状态恢复、兼容性拒绝、更新重载和健康插件继续运行。
