# Classic 效率与长程稳定性

本规格定义 Classic 五阶段的完整效率、恢复和上游适配行为。

## 流程深度与用户控制

Classic 保留五阶段职责与关键用户确认。对有明确边界的小任务，默认建议已有轻量预设并说明产物及验证差异，由用户确认后采用；不新增重复分类系统，不静默降低已选 full change 的要求。探索实验不自动获得保留实现代码的授权。

## 上游兼容与适配边界

支持已通过能力与版本快照验证的上游组合，测试记录实际版本和内容身份，不根据版本号猜测能力。按所需能力选择适配；缺少必需能力时明确说明升级要求，不静默生成不受支持的产物。测试保留不可变版本或内容身份，不宣称覆盖全部历史版本。

OpenSpec 产物就绪判断覆盖实现所需依赖的传递闭包。显式 skipped 与 schema 明确允许省略的设计产物，按对应能力合法处理；存在行为变化时不得自行省略规格。嵌套 capability 的完整路径进入上下文、变更检测与归档相关检查。不同版本对同一输入具有不同合法行为时，由明确的适配契约处理，而非让 Agent 反复补写删除文件。

Classic 拥有阶段状态、用户审批、审查预算和最终收尾。上游的额外计划、复核、停止或归档指令不得重复接管生命周期；不得修改上游原始 Skill。中文版本确认后同步英文，两者语义一致。

## 上下文与证据

需求、技术设计和任务内容变化必须使受影响的上下文失效；仅完成 checkbox 状态变化不重建设计上下文。任务删除、重命名、依赖或验收内容变化不得被错误当作纯进度变化。

恢复上下文与执行证据有效性独立判断。满足既有本地可复用条件且绑定输入、环境、日志仍有效的证据允许重新校验后复用；缺失、被篡改、过期或不满足复用条件的证据不得复用。

Guard 只读预检不消费一次性证据。成功阶段转换与证据消费保持原子一致，失败、并发竞争和恢复不得产生双重消费或未验证推进。

单次操作内重复读取相同输入可共享快照，但源文件、工作树、索引、依赖环境和相关配置变化必须被检测。不以 mtime 或模型自报作为内容一致性的唯一依据。

## 文档与任务状态

行为规格、技术设计和实施计划职责明确，不重复维护多份详细技术设计。轻量路径仍保留恢复所需的确认结论、约束、验收目标与下一步，而非只依赖聊天记忆。

任务完成状态只有一个权威来源，其余计划与检查点按稳定任务身份引用或派生。新增、重排、重命名、删除与恢复不得匹配错误任务；旧 change 应保留可读取与可恢复路径，无法安全映射时明确阻塞而非猜测。

入口提供当前动作所需的结构化状态；相关配置确认后原子更新。写入或上下文边界变化后刷新状态，不以缓存跨越授权与状态版本边界。

## 自主执行与审查

同类、低风险、可共同验收的微任务允许有限合批；复杂或互相独立的判断保持隔离。批次仍能逐项关联实现、测试和任务状态，中断后不得重复执行已验收工作。

Implementer 与 reviewer 角色独立，不自行嵌套派发重复 reviewer。文件交接只带当前任务所需上下文；复查覆盖未解决问题、修复和新增风险；Classic Verify 负责唯一最终集成审查，实际执行验证不可被 OpenSpec 语义审查替代。

规格内可逆实施决定可自主处理并持久化必要理由。范围扩张、规格或验收放宽、安全例外、接受重要缺陷及外部副作用仍遵循用户授权。临时子代理工作区被清理后，恢复所需决定与证据仍可读取。

## 路径、入口与恢复

文件操作提供绝对路径；design_doc、plan 和任务 authority 提供受保护的仓库相对引用，调用方无需自行转换。legacy/docs 配置缺省遵守既有解析行为；文档不得改变默认。项目根与嵌套目录对同一合法引用得到一致判断，显式检查子进程 cwd 继续独立生效。越界、symlink/junction 逃逸和其他 change authority 仍拒绝。

Design 已登记有效文件的中间状态允许正常恢复，普通入口与冷恢复具有一致语义；过期 handoff 返回刷新动作，缺失或错误归属精确阻塞。不清空设计，不重做已确认成果，不把路径为空用作确认凭证。

同一授权边界内的成果登记、handoff 和 Guard 推进由可恢复操作协调；前置失败不触发不必要的重检查，中断后保留成果并只完成剩余步骤。用户确认和安全验证不能被该协调动作合并跳过。

公开执行动作、错误投影、插件及上游适配遵守 agent-cli-contract；读取共享及基准遵守 workflow-cli-efficiency。Open 首次兼容性 status 在无修改时直接作为产物循环输入，同次操作内有效的上游状态不重复调用，文件或 schema 改变后刷新。

## 真实模型评估

模型 Eval 按用户对具体执行的授权启动，不自动扩大为付费批量实验。需要前后比较时固定任务、验证器、模型、Agent、依赖和环境；完整保留成功、失败和中断样本，不补齐缺失 usage，不以失败低消耗证明效率。无完整对照时仅报告确定性测试和真实 CLI 基准，不声称 token、模型纠正比例或总任务耗时获得特定改善。凭据仅使用进程级配置，不落入项目产物或报告。
