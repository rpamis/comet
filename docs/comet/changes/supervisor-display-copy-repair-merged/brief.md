# 目标

确认 Native Supervisor 验证保证级别在报告、Dashboard 和 CLI 帮助中的用户可读展示，并保持机器字段不变。

# 范围

- 统一四种验证保证级别的中文用户文案。
- 已确认的 `skill-coordinated` 结果显示为已确认。
- 复核展示文案回归。

# 非目标

- 不修改 Portable State、status JSON 或旧状态读取中的原始枚举值。
- 不改变验证流程、归档流程或验收范围。

# 验收示例

- Dashboard 和 verification report 对同一状态使用相同文案。
- 用户确认后不再显示“需要你确认”。

# 约束与不变量

- 四个 assurance 枚举保持原样。
