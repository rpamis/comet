# 项目知识详情卡片与文件预览设计

## 背景

项目知识页顶部的“最近一次任务使用的项目知识”目前在页面原地展开详情，长内容会改变主页面布局，且与设置页的交互方式不一致。数据来源点击后虽然可以打开来源详情，但文件正文仍以原始 `<pre>` 文本展示，Markdown 和 JSON 不具备可读的预览效果。

## 目标

1. 将项目知识顶部概览项改为弹出式详情卡片，不再在列表原地展开。
2. 将数据来源文件改为弹出式预览卡片，并支持全屏阅读。
3. 复用 Classic/Native 产物预览的 Markdown、JSON、YAML 渲染和文档目录行为。
4. 保留当前项目知识来源搜索、完整列表、关联记录跳转和已有 Dashboard 视觉语言。

## 非目标

- 不改变项目知识索引、检索、来源读取或 manifest 数据契约。
- 不改变个人记忆页面的现有交互；共享组件只在项目知识页面切换为弹出详情。
- 不新增文件编辑、下载或远程来源读取能力。

## 方案

使用一个项目知识专用的预览卡片组件承载两类内容：项目知识详情和来源文件预览。卡片采用现有设置页的 Ant Design `Modal` 容器，复用其圆角、遮罩、标题区和全屏状态样式；正文区域使用与 `ArtifactDrawer` 相同的滚动、目录和全屏布局约定。

### 项目知识详情

顶部概览项仍显示标题、类型、摘要和应用摘要，但点击后只打开“项目知识详情”卡片。卡片显示完整项目知识内容、为什么使用、提供给 Agent 的内容、应用结果和最近应用时间。关闭或切换项目知识时清理弹窗状态，不影响下方项目知识记录的选中状态。

### 来源文件预览

点击数据来源行后打开“项目知识来源详情”卡片。标题区显示来源路径、来源类型、文件大小和更新时间；关联项目知识保留为可点击列表。文件正文按来源扩展名选择预览：

- `.md` / `.mdx`：调用 `renderMarkdown`，渲染标题、列表、代码块和 Native 验收证据摘要；
- `.json`：调用 `renderJsonPreview`，对象和统一对象数组以结构化表格展示，其他形状使用格式化 JSON 代码块；
- `.yaml` / `.yml`：调用 `renderYamlTable`；
- 其他文本：调用 Markdown 的纯文本/代码块回退路径，不执行原始 HTML。

全屏时提供文档目录（存在标题时），正文独立滚动；关闭、Escape 和遮罩点击均可退出详情。加载、读取失败、空文件和截断状态在正文区域明确展示。

### 共享渲染边界

`markdown-preview.js` 继续作为唯一的 Markdown/JSON/YAML HTML 生成边界。项目知识预览组件负责文件类型判断、异步加载状态、目录提取和全屏状态；不复制渲染器逻辑，也不直接把来源内容作为未处理 HTML 注入页面。

## 测试设计

- 浏览器测试确认项目知识概览点击后打开对话框，页面内没有原地展开详情；详情卡片支持全屏切换。
- 浏览器测试确认 Markdown 来源显示渲染后的标题和正文，而不是只显示 Markdown 标记。
- 浏览器测试确认 JSON 来源显示结构化字段/表格，并支持全屏和关闭。
- 现有来源搜索、124 条来源滚动访问、列对齐、关联记录跳转和项目知识记录管理回归测试继续通过。
- Dashboard Web 源码契约和相关文件格式检查继续通过。

## 验收标准

1. 项目知识顶部概览项点击后出现设置页风格的“项目知识详情”卡片，原列表不插入展开区域。
2. 项目知识详情和来源文件预览均可切换全屏，关闭后回到原页面位置。
3. Markdown 文件以可读文档形式呈现；JSON 文件以结构化预览呈现；YAML 行为与现有产物预览一致。
4. 来源列表搜索、滚动、列对齐和 124 条完整来源的访问不回归。
