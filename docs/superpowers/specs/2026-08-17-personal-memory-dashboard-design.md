# 个人记忆 Dashboard 改版设计

## 背景

当前个人记忆页面把自动学习、注入、同步、项目暂停、Git remote 和卸载等操作全部平铺在同一行工具栏，同时把“当前画像”和“本次项目可用记忆”作为两个同等权重的卡片展示。页面能用，但信息层级接近 Demo：首屏没有明确的主任务，设置操作抢占了记忆内容，记录操作也缺少稳定的列表节奏。

## 目标

- 让用户进入页面后先看到“当前项目有哪些可用记忆”。
- 让自动学习、记忆注入和项目暂停状态一眼可读，但不占用主要内容空间。
- 把同步、remote、卸载等低频操作收进设置区域，避免工具栏拥挤。
- 保持 Dashboard 现有的浅灰工作台、白色内容面、细边框、蓝色强调和 Ant Design 组件语言。
- 保留所有现有能力与数据契约：纠正、回滚、删除、同步、remote、学习/注入开关、项目暂停和卸载。

## 非目标

- 不修改个人记忆 Plugin Runtime、服务端数据结构或 API。
- 不引入新的 UI 依赖，不重做 Dashboard 全局导航。
- 不增加搜索、分页、排序或新的记忆分类模型。

## 页面结构

1. `SectionHead` 保留，标题下增加轻量的项目上下文与文件数量信息。
2. 顶部状态带使用一组紧凑状态单元展示：自动学习、记忆注入、项目范围、记忆文件数。开关操作留在状态单元内，使用 Ant Design `Switch` 或紧凑按钮，不再把所有操作堆在工具栏。
3. 主内容采用响应式两栏：左侧为“可用于当前项目的记忆”列表，右侧为“记忆设置”面板。左侧占大部分宽度，空状态和冲突状态都在列表区域内表达。
4. 记忆记录使用列表行而不是嵌套卡片：分类作为小标签，正文作为主要信息，纠正/回滚/删除作为行尾次级操作；行之间使用细分割线。
5. 设置面板只承载低频操作：Git remote、同步、项目级暂停、插件卸载。卸载继续使用确认 Modal。
6. 现有提醒继续置于标题下方，但使用紧凑 Alert，避免推动主内容过远。

## 交互与状态

- `status.learningEnabled` 和 `status.retrievalEnabled` 直接控制两个状态单元中的开关。
- `pausedLearningProjects` 与 `pausedRetrievalProjects` 只影响当前项目的两个项目级操作，并以状态标签表达暂停。
- remote 未配置时显示“未配置”，输入框只在设置面板中出现。
- `status.sync` 为空时显示本地仓库状态，不制造虚假的同步进度。
- 记录没有新增操作；所有现有 `onInvoke` capability 名称保持不变。
- 深色主题复用现有 CSS 变量，不能写死白色背景或黑色文字。

## 响应式与可访问性

- 760px 以下切换为单栏，设置面板排在记忆列表之后。
- 记录操作在窄屏下换行，按钮仍保留可点击尺寸。
- 开关、设置分组和记忆列表使用可读的标题/aria-label；不能只依赖颜色表示开关状态。
- 保留 Ant Design 的键盘焦点和 Modal 行为。

## 验收标准

- 页面首屏主视觉是记忆列表，而不是横向拥挤的操作条。
- 所有旧能力仍可从页面触发，现有 Plugin/Memory 测试不需要改变数据契约。
- 亮色和暗色主题下边框、文字、状态色均来自现有 Dashboard 变量。
- 桌面宽度与 760px 以下窄屏均无横向溢出。
- Dashboard 前端构建和相关测试通过。
