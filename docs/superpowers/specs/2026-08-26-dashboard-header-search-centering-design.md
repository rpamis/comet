# Dashboard 顶部搜索框主工作区居中设计

## 背景

Dashboard 顶部 Header 位于侧边栏右侧的主工作区内，但当前桌面端搜索框使用 `--rail-w` 进行额外的水平偏移，导致它相对于整个应用框架计算位置，而不是相对于主工作区居中。侧边栏展开与收缩时，搜索框的位置也会产生不必要的偏移。

## 目标

- 让顶部搜索框始终相对于侧边栏右侧的主工作区几何中心对齐。
- 侧边栏展开或收缩时，只由主工作区宽度变化影响搜索框位置，不再使用侧边栏宽度补偿。
- 保持项目选择器位于左侧、刷新和主题操作位于右侧。
- 保持小屏幕下现有的 Header 换行布局。

## 方案

桌面端将 Header 采用对称三列布局：

1. 左列使用可伸缩空间承载项目选择器。
2. 中列使用固定范围承载搜索框，并让搜索框在该列中居中。
3. 右列使用可伸缩空间承载刷新与主题操作，并保持右对齐。

移除桌面端搜索框对 `--rail-w` 的 `left` 补偿和折叠状态特例。这样 Header 自身的内容宽度就是主工作区宽度，搜索框不依赖全局侧边栏尺寸。

## 不变范围

- 不修改全局侧边栏、项目选择器、刷新按钮和主题切换的功能行为。
- 不改变移动端 Header 的菜单、换行和操作区布局。
- 不调整个人记忆、项目知识或其他中心页面内容。

## 验收标准

- 桌面端搜索框的中心线与主工作区中心线重合。
- 侧边栏展开、收缩后，搜索框仍与主工作区中心线重合。
- 左右 Header 操作不覆盖搜索框，且右侧操作保持右对齐。
- 小屏幕下搜索框仍独占整行并可正常使用。
- 源码契约测试覆盖“使用主工作区对称布局、无 `rail-w` 搜索偏移”的约束。
