# Dashboard 侧栏稳定性设计

## 目标

消除桌面端 Dashboard 侧栏在展开和收缩时的跳跃感，并保证底部“设置”入口在展开、收缩及有限视口高度下始终可见、可操作。

## 范围

- 仅调整 `domains/dashboard/web/src/main.jsx` 的侧栏语义标记（如测试需要）和 `styles.css` 的桌面侧栏布局与过渡。
- 保持现有 228px 展开宽度、64px 收缩宽度、Ant Design 菜单行为、移动端 Drawer 和现有视觉配色。
- 不调整设置弹窗、插件导航、工作流数据或移动端导航。

## 根因

当前侧栏的宽度同时由外层工作台 grid、`Layout.Sider` 以及 `.dashboard-sidebar-content` 各自过渡；状态切换时三套宽度在不同 DOM 层并行变化，造成边界和内容位置不连续。设置入口仅依靠 `margin-top: auto` 推到底部，未明确约束其在收缩和内容空间被压缩时的占位。

## 方案

桌面端以工作台 grid 的 `--rail-w` 为唯一宽度动画来源：侧栏本体及其内容占满 grid 轨道，而不再独立动画 `width`、`min-width`、`max-width` 和 `flex-basis`。这样主内容区和侧栏边界使用同一条 220ms 缓动时间线。

设置区保留为侧栏垂直 flex 布局中的末尾项，增加不可压缩约束；收缩态将其固定为 40px 居中图标按钮，并保留已有可访问名称和 Tooltip。导航区域继续作为唯一可滚动区，不能把底部设置区挤出可视范围。

## 备选方案

1. 保留 Ant Design Sider 动画、取消外层 grid 与内容宽度动画：改动较小，但主内容与侧栏边界仍可能不同步。
2. 直接取消收缩动画：可移除跳跃，但不符合平滑过渡目标。

## 验收与测试

- 浏览器测试验证侧栏展开和收缩后均可找到“设置”按钮；收缩态按钮只显示图标但仍可访问并可点击。
- 浏览器测试验证收缩期间工作台和侧栏的过渡时长一致，且侧栏内容宽度随轨道填充。
- 保留 `prefers-reduced-motion` 的无动画行为。
- 运行相关 Dashboard 浏览器测试、源代码契约测试和受影响文件的 Prettier 检查。
