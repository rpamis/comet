# #519 实现与验证记录

日期：2026-11-01。来源：[Comet #519](https://github.com/rpamis/comet/issues/519)。本次按用户确认的简化方案实现项目级可选 HTML 变更说明，属于新增能力。

## 使用方式

项目默认生成可视化变更说明；配置可显式写为：

```yaml
# Native 与 Classic 共用；开启会增加讲解内容的 token 消耗。
change_walkthrough: true
```

缺省或 `true` 时生成变更说明；仅显式 `false` 时跳过详细指引、额外讲解整理和渲染，保留原有完成摘要。init、update 和项目激活保留已有选择（包括显式关闭）；新项目补默认值 `true`。本功能只读取项目配置，不提供全局或 Dashboard 开关。

Build 收尾时，Agent 从当前上下文与实际差异整理内容，调用 `comet walkthrough <native|classic> <change-name> --file <临时内容文件> --project-root <项目路径>`。临时 JSON 放在工作区以外，字段及示例见内置 Skill 的 `comet/reference/change-walkthrough.md`。命令返回生成页面的绝对路径：

- Native：`<native.artifact_root>/comet/changes/<change>/walkthrough.html`。
- Classic docs 布局：`docs/openspec/changes/<change>/walkthrough.html`。
- Classic legacy 布局：`openspec/changes/<change>/walkthrough.html`。

页面使用固定模板、内嵌样式与原生折叠元素。顶部概括结果，按功能展示原来／现在与原因，展开查看文件、增改删或重命名标签和关键代码，底部列真实验证结果。无外部资源或脚本，不需要 Dashboard、服务或插件。说明和代码均按文本转义。

Verify 仅更新验证结果时，临时文件只提供 `verification` 数组，并加 `--verification-only`；命令复用页面内已有内容。代码改变时更新受影响的讲解后重新渲染同一页面。Archive 随现有材料保存已有页面，回复链接使用实际归档路径；缺页不阻塞，也不在 Archive 补生成。关闭开关保留已有页面。

页面不属于实现检查输入；更新页面不推进 Run、增加批准或调用检查。失败保留旧页面，返回具体原因，原工作流可继续。未增加阶段、候选绑定或历史版本系统。

## 2026-11-02 按需关系图

在原有临时内容中新增可选 `diagrams`，支持短流程图及前后框线对照。模型提供节点、连线和标签，固定模板输出内嵌 SVG。带文件引用的节点通过页面内链接定位代码，并由浏览器原生展开所在详情；没有脚本、外部图形服务或 Mermaid 运行时依赖。图中的增改删／重命名标签沿用现有术语，中文、英文使用同一渲染器。

短图每侧支持 2–6 个节点、1–8 条从前向后的连线，每层最多两个节点；复杂循环或大关系需要拆分并在正文说明范围。非法引用、重复节点和反向连线会被拒绝，保留已有页面。图只关联本页已声明的代码详情，不构成新的候选绑定或运行证据。省略图的旧页面仍可更新；`--verification-only` 保留已有讲解和图形。默认关闭、小改动可不画图、原流程与检查输入规则保持不变。
