实验与展示方法

两个数据集各选择低、中、高难度一题，每个题目、每种执行方式展示三次结果，共 36 个展示计分位置。使用相同 DeepSeek 配置、Claude Code 2.1.318、原题与原评分器，不额外注入领域 Skills。遥测记录出现 deepseek-flash[1m] 与 deepseek-v4-flash 标签；相同配置名不等于保证上游后端版本固定。

完整批次先比较满分次数，再比较平均原题得分；对指定零分位置，额外单次得分更高时可替换。全部来源保留。指标是结果择优展示的观察值；两组可选记录数量不同，不代表同等运行预算下的随机对照。

原题得分与执行状态

原题满分与自然结束、Native 流程完成分别统计。车辆调度保留的正确候选可取得原题满分，但超时不能写成自然结束。该任务 Native 原题满分 3/3、满分且自然结束 2/3；Goal 分别为 2/3、1/3。Native 流程通过为 2/3。

评分环境失败时只对保存的原候选评分，不修改候选、不再次调用模型，也不伪造缺失的流程检查或退出码。

比较边界

  • 缓存题的原评分器还检查 gettz 与 tzstr 缓存行为，公开题面明确提及的是 tzoffset 及可调缓存。部分得分不等于完全未完成。
  • Native CLI 为实验冻结的 0.5.3；可执行包与模型可读上下文分别核对，不声称所有本地脚本副本都与冻结包逐字一致。
  • 这是分层选样与结果择优展示，不代表完整官方榜单，也不能从个别场景推断全部任务表现。
  • Token 仅覆盖可观测记录，CLI 估价不等于模型账单；本表不据不完整遥测做费用排名。
