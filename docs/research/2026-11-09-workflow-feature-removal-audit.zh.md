## 性能

48 次计时调用均退出 0。原始结果与范围见[性能数据](2026-11-09-workflow-removal-performance.json)。使用删减前与当前自包含 Runtime，独立临时 Git 项目和用户 Runtime 目录，空项目与 2000 个约 1 KiB 文件项目各交替三轮。只计实际成功调用；临时夹具准备不计时。

原版本的 next --session 不能领取 Shape，因此不拿不同语义的命令直接比较；Native 比较两边共有的 new / status，Classic 比较同一 Compat Build 检查的首次与重复执行。Classic 夹具通过公开 state 命令配置，阶段配置只属于隔离测量场景，不代替真实审批流程验收。

未运行仓库全量、模型 Eval、真实 Agent 平台 Hook、npm 包端到端安装或发布验收。测试退休不等于原已撤下策略仍得到保证。
