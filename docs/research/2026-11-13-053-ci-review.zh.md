来源：report:2026-11-13-053-ci-review。主 PR：https://github.com/rpamis/comet/pull/554；网站 PR：https://github.com/rpamis/comet-website-docs/pull/14。

## Windows Dashboard 路径

CodeQL 提示：https://github.com/rpamis/comet/security/code-scanning/51。

053 的 DSH 插件回退到 Windows npm `.cmd` 时，直接把 CLI 和工作区路径拼入命令。真实旧命令验证：含 `%COMET_DSH_LITERAL%` 的路径被替换为环境变量值，无法按原文传给 Dashboard。此插件是 053 新增功能，不是已发布版本回归。

修改后使用固定命令，将路径放入独立环境变量，并关闭延迟展开；拒绝引号、换行和 NUL。真实 Windows `.cmd` 进程验证 `%NAME%`、`!NAME!`、空格与 `&` 原样成为单个工作区参数，不执行路径中的命令文本。普通 Node 入口仍直接传 argv。

## CI 夹具

- 补齐九份当前 CLI 环境依赖，沿用现有依赖和 override 精确匹配断言。
- Native 当前 v4、Classic 当前 v2 通过外部 Python 进程执行真实测试，然后向公开 CLI 提交报告；不再调用已移除的受管检查执行接口。保留旧版本检查收据验证分支、批准、独立验收、一次性检查不重复、冷恢复、归档和不相关变更保护。
- 移除字节上限后的大内容继续验证非法 JSON 拒绝、输入原文不变和完整稳定读取；符号链接测试保留目标不变与拒绝行为，只更新错误文案。
- Classic Archive 使用明确标注的离线 OpenSpec 进程替身；真实 OpenSpec 上游兼容性仍由单独 CI 负责。
- Dashboard 浏览器检查保留原面板高度与滚动约束，沿当前“任务状态”侧栏验证。
- 三条历史选择器修正及完整证据见 [CI 选择器修正](./2026-11-13-ci-selector-repair/README.zh.md)。

这些是开发期夹具和评审修正，不另增版本或发布日志；当前版本仍为 0.5.3，master 为 0.5.2。
