## Windows Dashboard 路径

CodeQL 提示：https://github.com/rpamis/comet/security/code-scanning/51。

053 的 DSH 插件回退到 Windows npm `.cmd` 时，直接把 CLI 和工作区路径拼入命令。真实旧命令验证：含 `%COMET_DSH_LITERAL%` 的路径被替换为环境变量值，无法按原文传给 Dashboard。此插件是 053 新增功能，不是已发布版本回归。

修改后使用固定命令，将路径放入独立环境变量，并关闭延迟展开；拒绝引号、换行和 NUL。真实 Windows `.cmd` 进程验证 `%NAME%`、`!NAME!`、空格与 `&` 原样成为单个工作区参数，不执行路径中的命令文本。普通 Node 入口仍直接传 argv。

## macOS 终止确认

来源：`report:2026-11-13-macos-orphan-cleanup`，以及 [ef832ae8 的 macOS Runtime smoke](https://github.com/rpamis/comet/actions/runs/43279810282/job/131398013761)。真实孤儿后代用例在 bridge=true 时检出 `confirmed=true` 但后代仍存活。

Darwin 原先只有 SIGKILL 返回 EPERM 才等待整组消失，成功发送信号则立即确认。成功分支现在也复用既有的一秒整组退出探测；未退出或状态未知返回未确认，不重发组信号。ESRCH 已消失分支不增加探测。Windows 和 Linux 的既有清理路径保持原样。

四项确定性回归覆盖立即退出、延迟退出、仍存活和探测失败：旧代码四项失败，修正后通过；相关进程测试两文件共 29 项通过。原真实孤儿后代测试与成功收据的禁止条件没有缩窄。当前本机为 Windows，模拟 Darwin 系统调用不能代替真实 macOS 验收；该边界继续由最新 head 的 macOS Runtime CI 执行。这是 053 开发期间的 CI 修正，不新增发布日志条目。
