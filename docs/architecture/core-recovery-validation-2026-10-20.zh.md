# 核心恢复与规模验证记录（2026-10-20）

## 修复范围

1. SDK 请求隔离、严格结果校验、提交与冷读约束一致，原执行定义及领取身份可追溯，CAS 重试不重复外部执行。
2. Native / Classic 执行收据在升级、冷迁移与报告丢失后仍可校验；业务取消、实际停止、事务收尾分开记录，避免假自愈或重复执行。外部固定应用的恢复提示给出可执行参数，不再反复建议只读 inspect；正常检查完成后立即独立核验并记录停止事实，不把可继续的待办误导到 doctor。
3. Any 共享写入范围使用实际持有者索引，注册中断不能遗忘已发布成员；真实停止确认后释放占用，错误 token 保持阻塞。
4. 紧凑 checkpoint 共享历史累计值，冷读后仍按值标识复用，无变化更新和废弃树节点不放大磁盘写入。有限查询与分页绑定真实存储范围及 revision；领域适配器保留原已验证记录，避免误拒内部紧凑视图，已校验缓存冻结后才登记可信来源，不能后改 getter 绕过边界。
5. Dashboard 有界历史、稳定摘要、渐进发现和公平刷新；缓存失败不退回无界扫描，旧页面不成为新操作授权。
6. Eval 跨语言身份、矩阵和评分一致；完整失败与不完整运行分离，子集通过不冒充全量通过，结果修复保留原始坏字节并校验执行已停止。
7. Creator 验证只开放可信依赖目录，覆盖 pnpm、exports、CJS 和 Node 22 权限参数边界，不扩大到任意依赖根。

## 规模与安全边界

- 1,000 个真实 Run 场景，8 个独立进程竞争同一写入范围：1 个成功、7 个正确拒绝，无锁超时，均未读取无关 pending Run 正文。
- 逐次真实 FileStore 300 动作累计链：完整逻辑结果 93,757,293 字节，物理 checkpoint 1,260,504 字节、4,958 个树节点，规范摘要一致。current 只物化 598 项，完整读取物化 89,999 项，校验阶段零历史物化；累计执行约 395.68 秒，包含兼容完整返回和整 checkpoint I/O。
- 最终发布候选复用上述 300 动作数据进行冷读取复核：current 约 1,185 毫秒、full 约 1,565 毫秒，规范摘要一致；对原记录、标准化 Run、查询句柄、池化值的 13 项修改尝试全部被拒绝，getter 调用为 0，视图、hash 和磁盘均不变。
- 新领取后取消仍占用；错误 token 被拒且不释放；原宿主实际退出后确认停止，其他 Run 可成功领取。新周期没有人工清理或索引审计。
- 1,008 条记录 Dashboard 首次索引约 8.08 秒，缓存读取约 17.46 毫秒且不读 Run 正文。显式全库审计约 63.43 秒，单独索引初始化约 41.14 秒。

上述为共享 Linux / Node 24 测试环境样本，不是 SLA 或 p95。有限查询仍读取并验证整个紧凑 checkpoint；显式完整 API 仍可能展开很大的历史。首次索引、审计和恢复存在全库成本，尚不能据此宣称任意规模或全平台生产就绪。
